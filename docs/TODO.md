# Future Enhancements and Roadmap

## Planned Features
- [ ] **Wear OS Companion App**: Remote trigger and live viewfinder on Galaxy Watch / Pixel Watch.
- [ ] **Automated Cloud Backup Retries**: WorkManager-based periodic synchronization for failed network requests.
- [ ] **Custom Video Resolutions**: User option for 4K UHD and 720p battery-saver modes.
- [ ] **Biometric Decryption**: Direct fingerprint or face authentication prompt before playing encrypted files.
- [ ] **Audio Boost DSP**: Optional noise cancellation filter applied in real time to microphone audio stream.
